# ImageResizer

Настольная утилита, которая делает JPEG-копии картинок **рядом с собой**.

Готовые файлы: [Releases](https://github.com/kostin/ImageResizer/releases/latest) ·
[Actions](https://github.com/kostin/ImageResizer/actions) ·
[исходники](https://github.com/kostin/ImageResizer).

Положите `ImageResizer.exe` (Windows) или `ImageResizer` (macOS) в папку с картинками,
запустите — и для каждой картинки появятся две копии:

| Файл | Размер | Вес |
| --- | --- | --- |
| `762x1100_имя.jpg` | 762 × 1100 | до 5 МБ |
| `1524x2200_имя.jpg` | 1524 × 2200 | до 5 МБ |

Имя копии всегда начинается с разрешения (префикс), дальше идёт исходное имя.

## Что важно знать

- **Кадрирование по центру.** Картинка с другими пропорциями заполняет кадр целиком:
  лишнее по краям обрезается, пустых полей нет, картинка не растягивается.
- **Вес до 5 МБ.** Качество JPEG подбирается автоматически: берётся максимально
  возможное (до 95), при котором файл не превышает 5 МБ. Для обычных картинок
  качество остаётся высоким.
- **Один исполняемый файл без зависимостей.** Внутрь упакованы Python и Pillow,
  поэтому на целевой машине ничего устанавливать не нужно.
- **Папка определяется по расположению программы**, а не по текущей папке терминала:
  можно запускать двойным щелчком из любой папки.
- **Повторный запуск безопасен.** Созданные копии не считаются исходниками и не
  размножаются: второй запуск просто обновляет копии. Чужие не-JPEG файлы с
  совпадающим именем не перезаписываются.
- **Поддерживаемые форматы:** JPG, PNG, WEBP, BMP, GIF (первый кадр), TIFF, TGA,
  ICO, PCX, PNM, AVIF. Ориентация по EXIF учитывается, прозрачность заливается белым,
  метаданные в копии не переносятся.
- **Ошибки не прерывают работу:** битая или недоступная картинка попадает в отчёт,
  остальные обрабатываются.
- **Прогресс-бар и краткий отчёт.** Во время работы видно полосу, счётчик `3/12` и имя
  текущего файла; в конце — сводка: сколько копий, их общий вес, время и ошибки.

## Прогресс и отчёт

В терминале (в том числе при запуске двойным щелчком) строка прогресса обновляется
на месте:

```
[████████░░░░░░░░░░░░] 5/12 — фото 7.png — 1524x2200 → 2.61 МБ
```

В конце печатается короткий отчёт:

```
Итог: 12 картинок → 24 копии, 18.42 МБ, время 6.2 с, ошибок 0
  762x1100: 12 файлов, 5.31 МБ
  1524x2200: 12 файлов, 13.11 МБ
```

Если вывод перенаправлен в файл или в лог CI, полоса отключается автоматически и
печатаются обычные строки — по одной на файл. Принудительно включить строковый режим
можно ключом `--no-progress`.

## Как пользоваться

### Windows

1. Распакуйте `ImageResizer-windows-x64.zip` и положите `ImageResizer.exe` в папку с картинками.
2. Дважды щёлкните по `ImageResizer.exe`.
3. Дождитесь строки «Итог: …» и нажмите Enter, чтобы закрыть окно.

Первый запуск неподписанного `.exe` может показать окно SmartScreen — «Подробнее» → «Выполнить в любом случае».

### macOS

1. Распакуйте `ImageResizer-macos-arm64.tar.gz` (Apple Silicon) или
   `ImageResizer-macos-x64.tar.gz` (Intel) и положите `ImageResizer` в папку с картинками.
2. Снимите карантин (файл скачан из интернета и не подписан):

   ```bash
   xattr -d com.apple.quarantine ./ImageResizer
   ```

3. Запустите двойным щелчком (откроется Терминал) или из Терминала:

   ```bash
   cd /путь/к/папке/с/картинками
   ./ImageResizer
   ```

Если Finder отказывается запускать файл без расширения, используйте запуск из Терминала —
это штатный способ для консольных программ. Файл для каждого типа Mac свой: Apple Silicon
(`arm64`) и Intel (`x64`); универсальный бинарник PyInstaller собрать не может, потому что
Pillow не выпускает универсальных колёс для macOS.

## Сборка

### Windows

```powershell
pwsh -File tools\build.ps1
```

Результат: `dist\ImageResizer.exe` (~14 МБ). Скрипт сам поставит зависимости,
прогонит тесты и соберёт один файл. Дополнительно: `-SkipTests`, `-NoClean`, `-Python "C:\Python312\python.exe"`.

### macOS

```bash
./tools/build.sh
```

Результат: `dist/ImageResizer`. Дополнительно: `SKIP_TESTS=1 ./tools/build.sh`, `PYTHON=python3.12 ./tools/build.sh`.

### Вручную

```bash
python -m pip install -r requirements.txt
python -m PyInstaller --clean --noconfirm ImageResizer.spec
```

PyInstaller не умеет кросс-компиляцию: `.exe` собирается на Windows, бинарник для
macOS — на macOS. Поэтому автоматическая сборка под оба OS вынесена в GitHub Actions.

## Автоматическая сборка (GitHub Actions)

Файл `.github/workflows/build.yml` собирает три артефакта при каждом пуше и pull request:

| Артефакт | Что внутри | Runner |
| --- | --- | --- |
| `ImageResizer-windows-x64.zip` | `ImageResizer.exe` | `windows-latest` |
| `ImageResizer-macos-arm64.tar.gz` | `ImageResizer` для Apple Silicon | `macos-15` |
| `ImageResizer-macos-x64.tar.gz` | `ImageResizer` для Intel Mac | `macos-15-intel` |

В каждом прогоне CI дополнительно выполняется проверка собранного файла: бинарник
запускается на временной папке с картинками и должен создать корректные копии.

Чтобы получить релиз, поставьте тег:

```bash
git tag v1.0.0
git push origin v1.0.0
```

Тогда файлы из всех трёх сборок автоматически прикрепятся к GitHub Release.

## Аргументы командной строки

| Аргумент | Что делает |
| --- | --- |
| без аргументов | обрабатывает папку, где лежит программа, и ждёт Enter в конце |
| `--dir ПАПКА` | обрабатывает указанную папку |
| `--no-progress` | не рисует полосу, печатает по строке на файл |
| `--no-pause` | не ждёт Enter после завершения |
| `--help` | справка |

Коды возврата: `0` — успех, `1` — хотя бы одну картинку обработать не удалось,
`2` — папка недоступна, `130` — обработку прервали (Ctrl+C).

## Если окно закрывается сразу и копии не создаются

Программа собрана как один файл PyInstaller: при старте она распаковывается во временную
папку Windows (`%TEMP%`). Если окно моргнуло и закрылось без отчёта, чаще всего процесс
не может писать в `%TEMP%` — так бывает, когда папка с exe помечена **низким уровнем
целостности Windows (Low IL)**. Программа падает ещё до старта Python, поэтому не успевает
ни напечатать ошибку, ни дождаться Enter.

Проверить причину: скопируйте `C:\Windows\System32\whoami.exe` в эту папку и запустите
`whoami /groups` — строка «Низкий обязательный уровень» (`S-1-16-4096`) означает Low IL.

Лечение — запускать exe из обычной папки:

- переложите `ImageResizer.exe` в «Загрузки», на «Рабочий стол» или в папку с картинками;
- либо возьмите архив из [Releases](https://github.com/kostin/ImageResizer/releases/latest)
  (zip не переносит метки, поэтому распакованный файл запускается нормально).

`tools/build.ps1` сам проверяет запуск собранного exe: если он не стартует, печатает
предупреждение и кладёт рабочую копию в `%USERPROFILE%\Downloads\ImageResizer`.

## Структура проекта

```
ImageResizer.spec        спека PyInstaller (onefile, консольное приложение)
requirements.txt         Pillow + PyInstaller
src/resizer.py           ядро: поиск картинок, кадрирование, подбор качества
src/progress.py          прогресс-бар и журнал (тихий режим для логов)
src/image_resizer.py     точка входа: аргументы, вывод, отчёт, папка программы
tests/test_resizer.py    тесты ядра (unittest)
tests/test_progress.py   тесты отрисовки прогресса
tests/smoke_test.py      проверка уже собранного исполняемого файла
tools/build.ps1          сборка на Windows
tools/build.sh           сборка на macOS
.github/workflows/build.yml  CI: три сборки + релиз по тегу
HISTORY.md               журнал работ
```

## Тесты

```bash
python -m unittest discover -s tests -v          # все тесты (ядро и прогресс)
python tests/smoke_test.py dist/ImageResizer.exe # собранный файл
```
